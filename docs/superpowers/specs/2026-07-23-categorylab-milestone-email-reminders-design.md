# CategoryLab 档期节点邮件提醒设计

## 目标

CategoryLab 档期管理在网页关闭时仍能自动发送节点提醒。提醒只覆盖以下三个档期节点：

| 节点 | 提醒时间 |
| --- | --- |
| 原型开发 | T-15、T-7 |
| 众测 | T-15、T-7 |
| 中试 | T-15、T-7 |

默认时区为 `Asia/Shanghai`，腾讯云定时任务每天 09:00 扫描一次。节点已经填写实际完成日期时不再发送提醒；本期不发送逾期邮件。

## 收件人与邮件内容

固定收件人：

- Louise：`louise.lu@peets.cn`
- Chenko：`chenkoli@peets.cn`
- 魏莱 / Lainey：`pd_cw03@peets.cn`

邮件主题格式：

```text
[Category Lab 档期提醒][T-15] 8月：桂花1 · 众测
```

邮件正文只保留执行所需信息：档期名称、节点名称、节点计划日期、距离节点天数、上市日期，以及正式 CategoryLab 档期管理链接。

## 架构

### 1. 网页端同步

目前档期数据保存在浏览器 `localStorage`，腾讯云无法直接读取。新增提醒同步层后：

1. 用户首次开启云提醒时，使用 CategoryLab 管理码完成一次授权。
2. 腾讯云返回只允许同步档期提醒数据的独立令牌；管理码本身不写入源码，也不长期保存在浏览器。
3. 档期名称、上市日期、节点计划日期或实际日期发生变化并保存后，网页在短暂防抖后自动同步。
4. 页面显示“已同步 / 同步失败 / 正在同步”状态，并提供手动重试按钮。
5. 同步失败不影响网页本地保存，避免覆盖 Louise 已在网页端录入的数据。

只同步提醒需要的最小字段，不上传 Coffee Bar 全流程、备注或其他业务数据。

### 2. 腾讯云数据

新增两个集合：

- `categorylab_launch_reminders`：每个档期一条当前提醒快照，保存档期 ID、档期名称、上市日期，以及原型开发、众测、中试的计划日期和实际日期。
- `categorylab_reminder_deliveries`：记录已经处理的提醒，防止重复发送。

提醒唯一键由“档期 ID + 节点 + T-15/T-7 + 当前计划日期”组成。计划日期调整后，系统按新日期重新计算；旧日期对应的待发提醒自动失效。

### 3. 定时扫描与发送

腾讯云定时函数每天 09:00 执行：

1. 读取所有启用提醒的档期。
2. 跳过已填写实际日期的节点。
3. 距离节点 8–15 天且尚未处理时，发送 T-15。
4. 距离节点 0–7 天且尚未处理时，发送 T-7。
5. T-7 已进入发送窗口时，不补发更早的 T-15，避免同一天收到两封提醒。
6. 发送成功后写入发送时间、收件人和邮件 ID；发送失败记录错误，并在当前窗口内下一次扫描时重试。

邮件发送复用现有腾讯云 `nodemailer` 和 SMTP 环境配置，不在网页或 GitHub 中保存邮箱授权码。

## 首次启用规则

首次同步 FY26、FY27 档期时，不补发已经错过的历史提醒，避免一次性集中发送邮件：

- 启用日已经进入或越过的提醒档位记为历史跳过，但更晚的档位仍保留。例如节点还剩 10 天时只跳过 T-15，未来进入 T-7 时正常发送；节点只剩 5 天时跳过 T-15 和 T-7。
- 启用后新进入提醒窗口的节点才正常发送。
- 首次正式启用前，先只向 Louise 发送一封测试邮件；验证主题、正文和链接后，再开启三位收件人的自动发送。

## 安全与容错

- 同步接口必须校验独立的提醒同步令牌，不开放匿名写入。
- 定时函数只从腾讯云环境变量读取 SMTP 凭据和正式收件人。
- 邮件失败不能覆盖或删除档期数据。
- 重复执行同一天任务不会重复发信。
- 删除档期后，云端对应提醒记录停用，不再发送。
- 浏览器和腾讯云状态冲突时，以网页最后一次明确保存的档期版本为准，并保留更新时间。

## 验证

实施完成必须通过：

1. 单元测试：三个节点和两个阈值的窗口判断正确。
2. 单元测试：已完成节点、已发送提醒、历史提醒和删除档期均被跳过。
3. 单元测试：计划日期修改后旧提醒失效，新提醒按新日期计算。
4. 集成测试：重复扫描不重复发送；失败记录可重试。
5. 网页测试：保存档期后显示同步成功，失败时本地数据仍保留。
6. 真实测试：先只向 `louise.lu@peets.cn` 发送一封测试邮件。
7. 部署验证：GitHub、本地镜像和腾讯云版本一致，定时触发器状态可查询。

## 不在本期范围

- 逾期后的每日或周期提醒。
- Coffee Bar 每个食品任务的邮件提醒。
- 在邮件内直接修改节点日期。
- 将 CategoryLab 其他模块整体迁移到腾讯云数据库。
